## Software Engineering Intern, Cloud Insights and Telemetry
**Summer 2025**

The team builds the telemetry that shows MongoDB how its managed deployments behave.

- Extended the MongoDB Agent (Go) with a new collector that queries active deployment metadata
- Built a Java control plane endpoint that processes, tokenizes and streams that data to AWS Kinesis
- Tested the whole pipeline with unit, integration and E2E tests

**Stack:** Go · Java · AWS Kinesis
