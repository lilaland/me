# JSonic

A JSON formatter and differ in the Mac menu bar that reads what's on your clipboard.

---

## What It Does

Copy some JSON, click JSonic in the menu bar, and you get:

- **Formatted, highlighted JSON**, even from a one-line blob
- **A diff**: paste two JSON objects and see what changed, field by field
- **Validation**: whether the JSON is valid, and if not, where it breaks

It's for checking API responses, logs and config files without pasting them into a website or opening another app.

---

## How to Use It

1. Copy any JSON
2. Click the JSonic icon in the menu bar
3. JSonic loads, formats and shows it

To diff two objects, paste one into each pane. The differences are highlighted inline.
